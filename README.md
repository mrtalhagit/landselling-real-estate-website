# LandSelling.com — Real Estate Website

A modern and responsive real estate website designed to showcase land listings and property investment opportunities. Built using HTML and CSS.

## Features

- Modern real estate landing page
- Navigation bar with section links
- Property search interface
- Featured land and property listings
- Property categories
- Step-by-step land buying section
- Blog and insights section
- Client testimonials
- Responsive layout for mobile and desktop
- Hover effects and smooth scrolling

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Project Structure

```text
landselling-real-estate-website/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. For easier development, use the Live Server extension in VS Code.

## Note

Property images are loaded from external image URLs, so an internet connection is required to display them. Property listings and the newsletter are demonstration elements.
